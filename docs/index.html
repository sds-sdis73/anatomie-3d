Gestes

  • Un doigt : tourner autour du corps
  • Deux doigts : glisser pour déplacer, pincer pour zoomer vers les doigts
  • Toucher : nommer une structure ; toucher deux fois : centrer et rapprocher
  • Appui long sur une structure : masquer, isoler, rendre transparent, voir la fiche
  • Règle des couches : glisser le doigt pour enlever ou remettre les couches ; l’œil montre ou cache une couche ; appui long : n’afficher qu’elle (un second appui long rétablit tout)

À propos

Atlas d'anatomie 3D pour expliquer au patient. Fonctionne sans connexion une fois chargé (les systèmes viscéraux, vasculaire et nerveux central sont téléchargés la première fois qu’on les affiche).

Modèles 3D : Z-Anatomy (Gauthier Kervyn, Lluís Vinent), d'après BodyParts3D © The Database Center for Life Science — licence CC BY-SA 4.0. Les modèles ont été allégés pour cet appareil.

Fiches descriptives : Z-Anatomy, d'après Wikipédia — CC BY-SA.

Moteur 3D : three.js (licence MIT).

Cet outil sert à illustrer une explication ; il ne remplace ni un atlas de référence ni un avis médical.
