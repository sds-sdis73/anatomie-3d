# Anatomie 3D

Atlas d'anatomie 3D (os, muscles, ligaments, nerfs, fascias) pour expliquer une prise en charge au patient.
Page web autonome, pensée pour fonctionner sur une tablette ancienne (iOS 12) et hors connexion.
